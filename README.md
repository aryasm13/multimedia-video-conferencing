# Real-Time Multimedia Communication and Video Conferencing System

A simple real-time multimedia communication system developed as a Multimedia Systems course project.

## Planned Features

- Real-time audio and video communication
- WebRTC-based peer-to-peer communication
- Meeting rooms
- Camera and microphone controls
- Text chat
- Quality of Service monitoring
- Latency, jitter, packet loss, bitrate and FPS monitoring

## Technologies

- React
- Node.js
- Express
- Socket.IO
- WebRTC

## Status

Project development in progress.
